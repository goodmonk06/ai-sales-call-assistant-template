# AI営業通話アシスタント

電話営業スクリプトをAIで最適化・ログ管理するためのアシスタント。通話メモから次回アクションを提案。

## 機能

- **スクリプトテンプレート管理**: 対象顧客別の営業スクリプトを作成・編集
- **通話ログ記録**: 通話内容と結果を記録
- **AIフィードバック**: OpenAI APIを使用して、通話内容から以下を自動生成
  - 良かった点
  - 改善案
  - 次回使える効果的なフレーズ

## Tech Stack

- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: PostgreSQL + Prisma ORM
- **AI**: OpenAI API (GPT-4o-mini)

## セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.example`をコピーして`.env`を作成し、以下を設定：

```bash
cp .env.example .env
```

```env
DATABASE_URL="postgresql://user:password@localhost:5432/ai_sales_assistant?schema=public"
OPENAI_API_KEY="sk-..."
```

### 3. データベースのセットアップ

```bash
# Prisma Clientを生成
npm run db:generate

# データベースをプッシュ（開発環境）
npm run db:push

# または、マイグレーションを作成（本番環境推奨）
npm run db:migrate
```

### 4. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

## 使い方

### 1. スクリプトテンプレートを作成

`/scripts` ページで、営業スクリプトテンプレートを作成します。

**例: 歯科医院向けの営業スクリプト**

```markdown
# スクリプト名
歯科医院向け予約システム導入アポ取得

## 対象顧客
歯科医院

## 目的
予約システム導入のアポイント取得

## スクリプト本文

### 1. オープニング（10秒）
お世話になっております。〇〇システムの△△と申します。
院長先生はいらっしゃいますでしょうか？

### 2. 目的の説明（20秒）
本日は、歯科医院様の予約管理を効率化する新しいシステムについて、
簡単にご案内させていただきたくお電話いたしました。

### 3. 課題の確認（30秒）
現在、患者様からの予約受付や予約変更の対応に、
スタッフの皆様がお時間を取られているというお話をよく伺うのですが、
貴院ではいかがでしょうか？

### 4. 価値提案（40秒）
私どものシステムは、24時間オンラインで予約を受け付けられるため、
- 電話対応の時間を50%削減
- 予約の取りこぼしを防止
- 患者様の利便性向上

といった効果が出ております。

### 5. アポイント打診（20秒）
詳しいご説明とデモンストレーションには15分ほどお時間をいただければと思います。
来週のご都合はいかがでしょうか？

### 6. クロージング
ありがとうございます。それでは〇月〇日の〇時にお伺いいたします。
当日はよろしくお願いいたします。
```

### 2. 通話ログを記録

`/calls/new` ページで、実際の通話内容を記録します。

**例: 通話メモ**

```
院長先生と直接お話しできた。
現在は紙の予約台帳とExcelで管理しているとのこと。
月に2-3件、予約のダブルブッキングが発生しており困っているとのこと。

スタッフ3名で電話対応を分担しているが、診療中は電話に出られず、
折り返しの手間がかかっている点も課題として認識されていた。

デモの提案に対して「興味がある」との反応。
来週火曜日14時でアポイント獲得。
```

### 3. AIフィードバックを確認

登録後、AIが自動的に以下のフィードバックを生成します：

- **良かった点**: 効果的だったアプローチ
- **改善案**: より良い結果を得るための提案
- **次回使える一文**: 次の通話で使える効果的なフレーズ

## データベーススキーマ

### ScriptTemplate（スクリプトテンプレート）
- `id`: ID
- `name`: スクリプト名
- `targetProfile`: 対象顧客プロファイル
- `purpose`: 目的
- `bodyMarkdown`: スクリプト本文（Markdown）
- `createdAt`: 作成日時
- `updatedAt`: 更新日時

### CallLog（通話ログ）
- `id`: ID
- `scriptTemplateId`: 使用したスクリプトテンプレートID
- `callDate`: 通話日
- `outcome`: 結果（アポ獲得、検討中、見送りなど）
- `notes`: 通話メモ
- `aiFeedbackMarkdown`: AIフィードバック（Markdown）
- `createdAt`: 作成日時
- `updatedAt`: 更新日時
